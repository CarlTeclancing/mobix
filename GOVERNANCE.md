# Governance

Mobix is initially a maintainer-led open-source project.

- **Contributors** propose changes through issues, discussions and pull requests.
- **Reviewers** provide technical review but cannot merge without repository permission.
- **Maintainers** own roadmap decisions, API stability, releases, moderation and security triage.
- **Repository administrators** manage organization access, branch protections and publishing credentials.

At least one maintainer review and required automated checks are expected for merging into `main`. Native bridge/security changes should receive an additional qualified review where possible.

Maintainers should publish a real team/contact roster and a documented process for adding maintainers before announcing the public launch. No contributor should be promised commit or publishing access based solely on activity.
