# Code of Conduct

Mobix aims to be a welcoming, respectful, inclusive community for developers of all experience levels.

Participants must avoid harassment, discriminatory remarks, threats, personal attacks, doxxing, and spam. Assume good intent, critique ideas rather than people, and respect maintainers' review decisions.

Maintainers may warn, temporarily restrict, or permanently remove participants who violate these rules. Report concerns privately to the maintainers using GitHub's repository contact mechanism or the security contact described in SECURITY.md. A dedicated conduct contact must be configured before public launch.

This project intends to adopt the Contributor Covenant; maintainers should review and publish the current official full text before public launch: https://www.contributor-covenant.org/
